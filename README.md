# Core idea 

- you upload books and notes, An agent extracts concepts and relationships with every edge traceable to a specific spain of source text. When you add a second document, the system doesn't rebuild - it produces a changeset against existing graph, resolving which new concept are the same as existing ones, and flagging contradictions rather than overwriting. You review the proposed changes in batches. The graph then answers multi-hop questions that flat retrieval can't
